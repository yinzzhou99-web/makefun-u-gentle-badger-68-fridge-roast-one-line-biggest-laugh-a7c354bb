# Fridge Roast: One Line, Biggest Laugh

One line roasting a smart fridge's ice maker — it dispenses a single cube, sounds like a printer giving up, and acts like it just did you a favour.

## Entry

`main.py` writes one line to `/output/entry.txt`:

> My smart fridge's ice maker dispenses one cube, sounds like a printer giving up, and acts like it just did me a favour.

Standard library only, no network, no third-party packages.
